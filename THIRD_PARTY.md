# Third-party notices

MoonGCode is an original implementation. It does not copy source code, test fixtures, or assets from another G-code implementation.

The CLI uses `moonbitlang/x` for filesystem and process helpers. The dependency is resolved through MoonBit's package metadata and is used under its upstream Apache-2.0-compatible terms. MoonBit compiler/runtime components are build tools, not distributed source dependencies.

No external images, fonts, datasets, or proprietary controller protocols are included.

## Maintenance references

LinuxCNC G-code documentation and the Grbl 1.1 README were consulted for
semantic/capability comparison only. No controller code or upstream test data
was copied. Fixed source revisions and the limits of the comparison are recorded
in `docs/maintenance/REPORT.md`. All analytic fixtures are generated by this
project's Python standard-library script, not extracted from either controller.
