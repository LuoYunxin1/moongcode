# Originality record

The selected identity is deterministic G-code modal-machine interpretation, toolpath replay, geometry analysis, and CNC machine-profile safety preflight.

Before implementation, the MoonBit Hackathon registry was compared across problem domain, primary users, workflow, core data, algorithms, outputs, and acceptance demonstration. The project was also checked against MoonCakes modules and public MoonBit repositories using `gcode`, `g-code`, `cnc`, `toolpath`, and `machining` searches. No comparable G-code/CNC/toolpath project was found.

The project is intentionally outside the reserved identities for MoonBench (performance samples), MoonContract (OpenAPI contracts), MoonRecur (calendar recurrence), MoonShard (content-defined synchronization), MoonIndex/MoonSearch (full-text retrieval), MoonDispatch (message delivery), MoonPalette/colors (color conversion), and the other registry entries. Parsing, diagnostics, tests, and CI are shared engineering practices rather than the central workflow.
