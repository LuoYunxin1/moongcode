# Changelog

## 0.2.0 - 2026-08-21

- Added diagnostic queries, parser telemetry, detailed and Markdown reports.
- Added laser and external machine-profile audit workflows.
- Added reusable execution trace explanations and expanded CLI acceptance fixtures.
- Expanded the verified suite from 90 to 99 focused tests.

## 0.1.0 - 2026-08-21

- Added strict line-oriented G-code parsing with comments, checksums, canonical rendering, and diagnostics.
- Added modal execution for units, positioning, planes, motion, feed, spindle, tools, dwell, pause, and program end.
- Added IJK and signed-R arc solving, toolpath bounds, distance and duration statistics, and machine-profile safety audit.
- Added runnable `demo`, `validate`, `normalize`, `trace`, `analyze`, `audit`, and `explain` commands.
- Added portable/native CI, examples, tests, documentation, licensing, and originality disclosure.
